本文档用 Org 文学编程管理 Hyprland Lua 配置。
Lua 代码块 tangle 到 =hyprland.lua。
=hyprpaper= / =hyprlock= 用原生格式。

* 主修饰键

所有按键绑定共享的主修饰键（Win 键）。

#+begin_src lua :tangle hyprland.lua
local mainMod = "SUPER"
#+end_src

* NVIDIA 与环境变量

NVIDIA 驱动需要特殊的环境变量以确保 Wayland 正常工作。

| 变量 | 作用 |
|------+------|
| LIBVA_DRIVER_NAME | 硬件视频加速驱动 |
| XDG_SESSION_TYPE | 声明 Wayland 会话类型 |
| GBM_BACKEND | GBM 后端选择 nvidia-drm |
| __GLX_VENDOR_LIBRARY_NAME | GLX 库供应商 |

#+begin_src lua :tangle hyprland.lua
-- NVIDIA 驱动
hl.env("LIBVA_DRIVER_NAME", "nvidia")
hl.env("XDG_SESSION_TYPE", "wayland")
hl.env("GBM_BACKEND", "nvidia-drm")
hl.env("__GLX_VENDOR_LIBRARY_NAME", "nvidia")
#+end_src

** 应用缩放

Qt 和 GTK 应用的缩放设置。Firefox 120+ 自动支持 Wayland 分数缩放。

| 变量 | 作用 | 值 |
|------+------+-----|
| QT_QPA_PLATFORMTHEME | Qt 主题 | qt6ct |
| ELECTRON_OZONE_PLATFORM_HINT | Electron 后端提示 | wayland |
| GDK_SCALE | GTK 整数缩放 | 1 |
| GDK_DPI_SCALE | GTK DPI 缩放 | 1 |
| QT_SCALE_FACTOR | Qt 缩放因子 | 1 |
| QT_FONT_DPI | Qt 字体 DPI | 96 |

#+begin_src lua :tangle hyprland.lua
-- 应用缩放
hl.env("QT_QPA_PLATFORMTHEME", "qt6ct")
hl.env("ELECTRON_OZONE_PLATFORM_HINT", "wayland")
-- Firefox Wayland 分数缩放支持
-- Hyprland 使用 wp_fractional_scale_v1 协议，Firefox 120+ 自动支持
-- MOZ_ENABLE_WAYLAND=1 已在系统环境变量中设置
hl.env("GDK_SCALE", "1")
hl.env("GDK_DPI_SCALE", "1")
hl.env("QT_SCALE_FACTOR", "1")
hl.env("QT_FONT_DPI", "96")
#+end_src

* 输入法

fcitx5 输入法配置。Wayland 下 GTK 应用使用原生 text-input 协议，不需要 GTK_IM_MODULE。

| 变量 | 作用 | 值 |
|------+------+-----|
| QT_IM_MODULE | Qt 输入法模块 | fcitx |
| GTK_IM_MODULE | GTK 输入法模块 | 空（Wayland 原生） |
| XMODIFIERS | X11 输入法标识 | @im=fcitx |
| SDL_IM_MODULE | SDL 输入法模块 | fcitx |
| FCITX5_WAYLAND_IM | fcitx5 Wayland 支持 | 1 |

#+begin_src lua :tangle hyprland.lua
-- fcitx5 环境变量
-- Wayland 下 GTK 应用使用原生 text-input 协议，不需要 GTK_IM_MODULE
-- Qt 和 X11 应用仍需要 IM module
hl.env("QT_IM_MODULE", "fcitx")
-- unset GTK_IM_MODULE for Wayland native input method support
hl.env("GTK_IM_MODULE", "")
hl.env("XMODIFIERS", "@im=fcitx")
hl.env("SDL_IM_MODULE", "fcitx")
-- fcitx5 Wayland 支持
hl.env("FCITX5_WAYLAND_IM", "1")
#+end_src

* 显示器

** 缩放策略

不同显示器根据物理尺寸和 DPI 设置合适的缩放比例。

| 显示器 | 分辨率 | 物理尺寸 | DPI | 缩放 |
|--------+--------+----------+-----+------|
| eDP-1 (笔记本) | 1920x1080 | 14寸 (340x190mm) | ~157 DPI | 1.5 (高 DPI) |
| HDMI-A-1 (外接) | 1920x1080 | 24寸 (530x300mm) | ~92 DPI | 1.0 (标准) |

** 配置

#+begin_src lua :tangle hyprland.lua
-- 笔记本屏幕：
hl.monitor({ output = "desc:AU Optronics 0xAF90",mode = "preferred", position = "auto", scale = 1.0 })
-- 外接显示器：标准 DPI，无缩放
hl.monitor({ output = "HDMI-A-1", mode = "preferred", position = "auto", scale = 1.0 })
--任意屏幕
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.0 })
#+end_src

* 设备配置

光标：关闭硬件渲染（NVIDIA 兼容性）。
输入：美式键盘 + 鼠标跟随焦点。
绑定：允许工作区循环切换。

| 参数 | 作用 | 值 |
|------+------+-----|
| no_hardware_cursors | 禁用硬件光标 | true |
| kb_layout | 键盘布局 | us |
| follow_mouse | 鼠标跟随焦点 | 1 (启用) |
| allow_workspace_cycles | 工作区循环 | true |
| workspace_back_and_forth | 工作区往返 | false |

#+begin_src lua :tangle hyprland.lua
hl.config({
    general = {
        layout = "dwindle",
    },
    cursor = {
        no_hardware_cursors = true,
    },
    input = {
        kb_layout = "us",
        follow_mouse = 1,
    },
    binds = {
        allow_workspace_cycles = true,
        workspace_back_and_forth = false,
    },
    misc = {
        always_follow_on_dnd = true,
    },
    scrolling = {
        column_width = 0.85,
        direction = "right",
        fullscreen_on_one_column = true,
    },
})
#+end_src

* 自启动

=hyprland.start= 事件在 Hyprland 完成初始化后触发。
所有 =exec-cmd= 类型的自启动命令都应在此回调中执行。

** 启动项列表

| 程序 | 作用 | 延迟 |
|------+------+------|
| fcitx5 | 输入法守护进程 | 无 |
| dbus-update-activation-environment | D-Bus 环境更新 | 无 |
| waybar | 状态栏 | 无 |
| swaync | 通知中心 | 无 |
| hyprpaper | 壁纸 | 1秒 |
| wlsunset | 蓝光过滤 | 2秒 |

#+begin_src lua :tangle hyprland.lua
hl.on("hyprland.start", function ()
    hl.exec_cmd("fcitx5 -d")
    hl.exec_cmd("dbus-update-activation-environment --systemd WAYLAND_DISPLAY XDG_CURRENT_DESKTOP")
    hl.exec_cmd("waybar")
    hl.exec_cmd("swaync")
    hl.exec_cmd("sleep 1 && hyprpaper")
    hl.exec_cmd("sleep 2 && wlsunset -l 22.82 -L 108.32 -t 4500 -T 6500")
end)
#+end_src

* 布局切换

Super + Tab 在 dwindle / scrolling 布局间循环切换当前工作区。

#+begin_src lua :tangle hyprland.lua
hl.bind(mainMod .. " + TAB", function ()
    local layouts  = { "scrolling", "dwindle" }
    local workspace = hl.get_active_workspace()
    if not workspace then return end

    local next_layout = layouts[1]
    for i = 1, #layouts do
        if layouts[i] == workspace.tiled_layout then
            next_layout = layouts[(i % #layouts) + 1]
            break
        end
    end
    hl.workspace_rule({ workspace = tostring(workspace.id), layout = next_layout })
end)
#+end_src

* hyprlock 配置

锁屏配置。使用 JetBrainsMono Nerd Font 和 Nord 配色。

|------+------+-----|
| grace | 宽限时间 | 1500ms |
| no_fade_in | 淡入效果 | false |

general {
    grace = 1500
    no_fade_in = false
    disable_loading_message = false
}

background {
    color = rgb(26, 27, 38)
}

input-field {
    font_family = JetBrainsMono Nerd Font
    font_size = 22
    fail_color = rgb(245,85,100)
    check_color = rgb(138,212,113)
    caps_lock_color = rgb(245,200,100)
    fade_on_empty = true
    fade_timeout = 1200
    round_corner_radius = 20
    thickness = 4
    halign = center
    valign = center
    position = 0, 0
    placeholder_text = <i>Enter password...</i>
    dots_centered = true
    dots_size = 14
    dots_spacing = 10
    dots_rounding = 12
    inner_color = rgba(26, 27, 38, 0.85)
    outer_color = rgba(138, 212, 113, 0.4)
    outline_thickness = 3
}

label {
    text = " Secure Session"
    font_family = JetBrainsMono Nerd Font
    font_size = 18
    color = rgba(166, 227, 161, 0.95)
    halign = center
    valign = top
    position = 0, 80
}
