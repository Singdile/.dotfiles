* Waybar 配置说明
** 组织结构
1. 主配置文件 (config.jsonc)
 定义全局设置（layer, height, spacing), 通过include引用`modules/`下的模块配置,定义模块布局（左/中/右）
2. 模块目录 (modules/)
   -  每个功能独立（audio, battery, clock等）
   - 便于维护和复用
3. 样式文件 (style.css)
   - 统一定义所有模块的外观
** 功能模块说明
- 工作区: 5个工作区，显示在最左侧.通过 super + n/p 滑动
- 内存显示: 显示当前内存使用占比，使用百分比的呈现形式。
- 时间显示: 位于中间位置，使用24小时制度。点击切换查看日期。
- 网络连接显示: 位于右侧，点击弹出我当前使用网络连接工具。
- 电量显示: 显示当前的电源连接情况和电量使用情况。
- 音量显示: 显示的当前的音量，点击可以呼出音量调节程序。
- 后台应用显示: 目前不启用托盘图标，避免依赖图标字体。
** 样式说明
- 配色 :: 采用tokoyo night的配色方案
- 透明度 :: 0.8左右
- 图案 :: 全部使用纯文字描述，避免依赖图标字体
** 注释说明
主配置文件对于每一个模块的内容注释清楚，以及涉及到的样式位置注释清楚
** 实现说明
对于功能模块的实现，首先先写测试，再实现。
